The artwork is unchanged. Brand source revision: 886b092c557184d38d57f76b91456f5becc30b9e.
The brand colour and font values are in brand.toml.
PT Sans is distributed under the included SIL Open Font License.
Font source: https://github.com/google/fonts/tree/main/ofl/ptsans.

XFeat source: https://github.com/verlab/accelerated_features.
ONNX export source: https://github.com/DavideCatto/XFeat-ONNX.
The Apache-2.0 notices are included. ONNX Runtime uses the included MIT licence.
The model preparation command writes its checksum and source identity.

The example image is rendered from the approved public NAIP package.
Its pack identity and assumed camera values are in demo-frame.json.
It shares reference evidence and does not measure absolute accuracy.
